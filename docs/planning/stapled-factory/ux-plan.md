# Control-plane UX plan

The operator sees work units, their stage, usage and outstanding approvals. Selecting a unit shows its receipt and a concise failure or approval reason. Approval requires an explicit decision and recorded identity; unavailable or stale state is shown as unknown, never as approval. The harness engineer can inspect invocation status and use the Restate operations surface to pause or cancel work. The dashboard is a later scope item; Phase 9 verification does not require it.
