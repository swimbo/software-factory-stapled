# Control-plane UI plan

Use the existing fullstack template for a local React control plane. Provide a work-unit list with status and usage, a detail view with receipts and failure states, and an approval queue with explicit approve/reject actions. Make controls keyboard accessible, label status in text, and show loading, empty, stale, and error states. Do not expose holdout content, credentials, or raw secrets. Visual design and implementation remain to be verified when the dashboard is built.
