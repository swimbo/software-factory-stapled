# NUC runtime image and dependency audit — 2026-10-28

## Decision and scope

The image/dependency review is complete for **one operator, bounded isolated work units on the NUC**, subject to the runtime containment checks and signed release approval. No dependency finding below establishes a reachable escape from that boundary or a vulnerability in the credential-bearing proxy's request path. This is a scoped risk assessment, not a clean vulnerability scan, exhaustive dependency attestation, enterprise certification, or approval to expose these services publicly. The operator's release approval must explicitly accept the retained findings and coverage limits.

The threat boundary already permits arbitrary agent code **inside** the disposable workspace container. Browser, document parser, shell and editor vulnerabilities inside that container still matter for task integrity and availability; they do not by themselves add host privileges or access to the separately held gateway credential. This assessment depends on independently verified non-root execution, no Docker socket/host namespaces, restricted mounts, dropped capabilities/no-new-privileges, resource bounds, worker network denial and fixed gateway-only proxy egress. Recheck those conditions before dispatch; failure invalidates this decision. Unattended multi-tenant or privileged deployment is outside scope.

## License inventory and use boundary

[The package inventory](evidence/runtime-audit-2026-10-28/runtime-package-inventory.json) retains scanner-discovered license identifiers, including GPL/LGPL, permissive and unknown/custom labels. Scanner `restricted` severity means license-policy classification, not a security CVE or automatic prohibition. Preserve upstream copyright/license files in images and retained source; there is no binary redistribution or public hosted platform in this deployment. Missing or ambiguous metadata is explicitly unknown, not MIT by default.

OpenHands source at the verified revision is MIT. Restate's verified revision uses **Business Source License 1.1**, with an additional use grant excluding a **Public Restate Platform Service**: providing third parties direct Restate APIs to register/invoke their services. A private factory used by this operator does not provide that service. Retain [the exact upstream license](https://github.com/restatedev/restate/blob/954797e4a36cf146ab4261cf0b6622375d1f5ae6/LICENSE); public managed service or redistribution needs a separate license review. The license changes to Apache 2.0 four years after release under its stated terms. This is a use-scope assessment, not a comprehensive legal opinion.

## Reproduction and verification

Raw JSON, npm audit, frozen metadata, source lock, upstream license snapshots and scan hashes are retained outside Git at `/Users/bo/.local/share/stapled-factory-audits/2026-10-28/` as deterministic gzip files. No credential values were collected. The repository stores normalized inventories/findings, compact receipts and a reproducible summarizer. Scan commands were `trivy image --image-src docker --scanners vuln,license --list-all-pkgs --format json` for local exact IDs; `trivy image --input` for the NUC Docker export; and `trivy fs --include-dev-deps` for the factory lock. Frozen metadata used `trivy fs` after extraction. The supplemental upstream lock is labeled separately.

`npm audit --json` returned zero findings including development dependencies. Verification also reconciled all **3006** worker raw matches to summary counts (no suppression), extracted **27** frozen metadata records, and proved the summarizer rejects missing scan results rather than treating malformed input as green. No exploit or model calls, service activation, remote build, shared daemon restart or dependency changes were performed by this audit. Release approval must bind this report, receipts and exact provisioned identities; a new image requires a new scan.
